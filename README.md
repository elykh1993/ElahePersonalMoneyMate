# 💚 MoneyMate 2.1 — مدیریت مالی شخصی با تقویم شمسی

یک وب‌اپلیکیشن تک‌صفحه‌ای، راست‌چین و فارسی برای مدیریت درآمدها، هزینه‌ها و بودجه‌بندی شخصی. این پروژه برای تمرین Vibe Coding و با کمک ChatGPT ساخته شده است.

## قابلیت‌ها

- داشبورد: موجودی خالص، درآمد و هزینه ماه انتخابی، نمودار روند شش ماه و نمودار دسته‌بندی
- تقویم **واقعی شمسی (جلالی)** برای انتخاب تاریخ در ثبت و ویرایش تراکنش؛ ناوبری قابل استفاده ماه قبل/بعد و پنجره مستقل بدون اسکرول افقی
- گزارش‌ها، خلاصه ماهانه و بودجه مستقل برای هر ماه شمسی
- افزودن، ویرایش و حذف تراکنش‌ها و مدیریت دسته‌ها
- جست‌وجو، مرتب‌سازی و فیلتر بر اساس نوع و دسته‌بندی
- خروجی CSV و پشتیبان‌گیری و بازیابی JSON
- حالت روشن/تاریک، طراحی ریسپانسیو و منوی موبایل
- داده آزمایشی جداشده و قابل حذف برای نمایش سریع
- نگهداری اطلاعات با `localStorage` بدون ثبت‌نام، API یا سرور

## فناوری

- HTML5 + CSS3 + JavaScript خالص (بدون فریم‌ورک، بدون `npm`، بدون build)
- `Intl.DateTimeFormat` با تقویم Persian و یک تبدیل معکوس مطمئن برای تبدیل تاریخ انتخابی به ISO
- SVG داخلی برای آیکن‌ها و نمودارهای تعاملی با CSS
- فونت Vazirmatn از Google Fonts با فونت جایگزین دستگاه در صورت نبود اینترنت

## اجرای پروژه

کافی است `index.html` را با مرورگر باز کنید. برای پیش‌نمایش محلی قابل‌اعتمادتر نیز می‌توانید داخل پوشه اجرا کنید:

```bash
python -m http.server 8000
```

سپس آدرس `http://localhost:8000` را باز کنید. این دستور اختیاری است و پروژه در Netlify و GitHub Pages بدون نصب و build منتشر می‌شود.

## انتشار

- **GitHub:** همه فایل‌ها باید در ریشه ریپازیتوری کنار `index.html` قرار بگیرند.
- **Netlify:** Import from Git با شاخه `main`، دستور build خالی و Publish directory برابر `.`، یا Netlify Drop برای آپلود پوشه
- **Vercel:** درصورت دسترسی به حساب، Framework = Other، Root = `./`، Build Command = خالی

راهنمای آپلود فارسی در `DEPLOY_GUIDE_FA.md` آمده است.

## حریم خصوصی و داده‌ها

اطلاعات صرفاً روی همان مرورگر و دستگاه در `localStorage` ذخیره می‌شوند و بین دستگاه‌ها همگام‌سازی ندارند. برای نگهداری اطلاعات، از بخش گزارش‌ها پشتیبان JSON تهیه کنید. پاک‌کردن داده‌های مرورگر ممکن است اطلاعات را حذف کند. این اپلیکیشن به بانک متصل نیست و مشاوره مالی یا قابلیت AI آنلاین ندارد.

برای هماهنگی با نسخه قبلی MoneyMate از همان کلید ذخیره‌سازی `moneymate-data-v1` استفاده شده؛ ساختار قدیمی درآمد، هزینه و بودجه در اولین بارگذاری خوانده می‌شود.
