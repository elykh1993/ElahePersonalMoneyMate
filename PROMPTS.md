# سه پرامپت مهم پروژه MoneyMate — برای تحویل تکلیف Vibe Coding

## پرامپت ۱: ساخت نسخه کاربردی

> Build a complete, responsive Persian RTL personal finance web app called MoneyMate, using only HTML, CSS and vanilla JavaScript so that it can run without a paid AI platform, build tools, a backend or external APIs. Include income/expense recording, edit/delete transactions, accurate balance calculations, a monthly budget, charts, categories, search, filters and persistent localStorage. Use a modern, polished fintech design and Persian toman currency throughout. Add clear empty states and optional demo data, but never present demo transactions as real information.

**هدف:** تبدیل ایده به اپلیکیشن واقعی قابل اجرا و انتشار بدون هزینه.

## پرامپت ۲: رفع ایرادات و تقویم شمسی واقعی

> Rebuild MoneyMate with a complete Solar Hijri (Jalali/Persian) date experience. Remove the unwanted one-letter avatar next to the Add Transaction button. Replace the Gregorian native date picker with a custom interactive Persian calendar showing Persian months and weekdays, correct leap years, and Saturday-first weeks. Use Persian months consistently for monthly budgets, charts, and filtering. Keep transaction dates internally in ISO format so older localStorage records still work. Do not reset form input when a category changes, and ensure all interactions work on desktop and mobile.

**هدف:** رفع ایرادهای نسخه قبلی، یکپارچه‌سازی تقویم شمسی و حفظ اطلاعات.

## پرامپت ۳: ارتقای تجربه کاربری و تست پروژه

> Redesign the interface as a premium, mobile-first Persian fintech dashboard with a tasteful dark navy sidebar, emerald accent, elegant summary cards, category donut, six-month income/expense bar charts, responsive navigation and light/dark themes. Add monthly budgets with overspending alerts, safe input validation, search/sort/type/category filters, CSV export and JSON backup/restore. Test adding/editing/deleting, monthly calculations, date conversions, data persistence, downloads, responsive layout, and error handling in a real browser. Package the application and documentation as a ready-to-upload ZIP with all web files at the repository root.

**هدف:** ارتقای کیفیت ظاهری، کامل‌کردن امکانات و تحویل پروژه قابل ارائه.

---
**ابزار هوش مصنوعی استفاده‌شده:** ChatGPT (کمک به ایده‌پردازی، تولید کد، بازطراحی، اشکال‌زدایی و مستندسازی).
